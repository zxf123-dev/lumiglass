三步用起来

不需要懂设计，也不需要改配置

1 拷贝 glass 目录

把 glass/ 文件夹整个复制进你的项目，它是全部内容。

2 引入三个文件

core + web（或 mobile）+ js，加起来三行 <link>。

3 照抄类名

写 class="glass" 就有玻璃，class="btn primary" 就有主按钮。

为什么是 Lumi Glass

把 Apple HIG 的 Liquid Glass 规范，翻译成网页能直接用的 CSS

◈ 三层真实配方

不是「磨砂白贴图」：backdrop 模糊提饱和 + SVG 折射滤镜 + 镜面高光边缘，和 iOS 同一套原理。

◐ 明暗双主题

一个 data-theme="dark" 属性全站切换，Token 级适配，跟随系统也可选。

⇄ 两端各一套密度

手机端命中区 ≥44px、网页端桌面密度；同一套 HTML 思维，两种舞台。

⚡ 零构建零依赖

没有 npm、没有打包、没有运行时框架——纯 CSS 文件 + 一个可选的小脚本。

♿ 无障碍内建

减弱透明度 / 减弱动效时自动降级为实底，键盘焦点环完整，对比度达标。

📖 中文文档齐全

设计原理、Token 表、90+ 类名速查、性能预算、接入检查清单，全部中文。
