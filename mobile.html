02

导航

Navigation

手机端的导航只有三种：胶囊导航条、大标题、Tab Bar。它们都悬浮在内容上，且滚动时不改变高度（避免布局跳动）。

设置

导航条 Navbar · 高 52，圆角 26；返回键自带一层薄玻璃，右侧操作不做背景

下拉菜单 · 与网页端相同 `.dd` + `.menu.glass` + `.mi` 结构

资料库

268 个文件 · 最近同步 2 分钟前

大标题 Large Title · 34px 粗体 + 11px 字距拉开的眉标；它本身也是玻璃，可直接盖在照片上

Tab Bar · 选中项浮起一枚白色玻璃，未选中图标降饱和；5 项是上限，再多就该换成分组

深色场景 · 同一组件放在深色照片上：文字自动跟随 token，白色高光降到 52% 才不会发亮

03

按钮

Buttons

手机端按钮高度统一 50px（小号 38px），左右内边距 ≥20px。主操作永远只有一颗，其余降为 tinted 或 ghost。

八种形态 · regular / primary / tinted / danger / ghost / small / icon；图标按钮必须是正方形，圆角取半径的一半

加载 / 分裂 · loading 隐藏文案并显示旋转描边，按钮宽度不变化，避免布局抖动

NEW

FAB · 58px 圆钮，悬停放大 8% 并旋转 90°；触屏上只保留 scale 1.06

04

输入

Inputs

外壳是玻璃，内部 input 完全透明。移动端字号不要小于 15px，否则 iOS Safari 聚焦时会自动放大页面。

所有控件的输入区都要 ≥44px。开关有三档：设置行用 44×26，表单用 52×30，大卡片用 62×36。
